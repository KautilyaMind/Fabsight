# FabSight — Synthetic Semiconductor Process Intelligence Agent

FabSight is a portfolio and educational project for exploring how AI process
intelligence might be applied to semiconductor manufacturing. Version 0.1 builds
only the clean, relational data backbone needed for later learning exercises.

> **Data notice:** Everything generated by v0.1 is synthetic educational simulation
> data. It does not use or reproduce Micron manufacturing data, equipment
> configurations, sensor definitions, recipes, products, alarms, or SOPs.

## What v0.1 does

It creates a deterministic, simplified fab environment:

```text
Lots
 ↓
Wafers
 ↓
Process steps
 ↓
Tools
 ↓
Process events
```

It also creates generic fictional maintenance and alarm records linked to tools.
Every wafer follows seven broad educational stages: clean, deposition, lithography,
etch, implant, CMP, and inspection. These are conceptual abstractions, not recipes.

## What v0.1 does not do

- No real Micron manufacturing data or product definitions
- No proprietary recipes, procedures, tool configurations, or alarm definitions
- No machine learning or causal defect simulation
- No wafer images or vision system
- No SECOM or WM-811K integration
- No LLM, agent, LangChain, or LangGraph
- No API, dashboard, or deployment framework

Those capabilities are deliberately reserved for separately scoped future versions.

## Setup

Python 3.11 or newer is recommended.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Generate and validate the data

From the repository root, run:

```powershell
python scripts/generate_synthetic_fab.py
```

The command writes seven CSV files to `data/synthetic/`, prints row counts, and
automatically validates IDs, foreign keys, mandatory values, durations, and process
ordering. Generation uses the fixed seed in `src/fabsight/config.py`, so rerunning
with the same code and dependency versions produces the same CSV content.

To run validation separately:

```powershell
$env:PYTHONPATH = "src"
python -m fabsight.validation.validate_data
```

## Run the tests

```powershell
python -m pytest
```

The tests check file creation, unique IDs, foreign keys, process order, lot counts,
and byte-for-byte deterministic generation.

## Repository guide

- `src/fabsight/generators/` contains readable table-generation functions.
- `src/fabsight/validation/` contains relational and timeline checks.
- `scripts/` contains the command-line entry point.
- `data/synthetic/` contains generated CSVs.
- `docs/data_model.md` explains each relationship for beginners.
- `tests/` contains focused pytest coverage for v0.1.

Random `WARNING` and `FAILED` process statuses are independent synthetic workflow
events. They are not caused by tools, maintenance, alarms, or simulated sensors.
